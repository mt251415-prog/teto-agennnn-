# 🧪 테토 vs 에겐(Teto vs Egen) 성향 진단 웹사이트

[Types(타입스)](https://types.my/egen-teto)의 에겐/테토 성향 테스트를 벤치마킹하여 제작된 **바이럴 심리 성향 진단 웹 애플리케이션**입니다.

---

## 🌟 주요 특징 및 구현 기능

1. **모바일 퍼스트(Mobile-First) 감각적 UI**:
   - 가로 최대 480px의 인스타그램/모바일 메신저 최적화 레이아웃
   - Pretendard 웹폰트 & Tailwind CSS를 적용한 세련된 다크 글래스모피즘 디자인
   - 실시간 상단 프로그레스 바(Progress Bar) 및 부드러운 화면 전환
2. **정밀한 12가지 양자택일 밸런스 문항**:
   - 일상, 갈등 대처, 데이트 리드, 소통 화법, 연애 플러팅 등 다양한 상황별 A/B 선택지
3. **4대 본능 성향 분석 & 궁합 매칭**:
   - **테토남(🐺 불도저 늑대)**: 결단력과 추진력의 직진남
   - **에겐남(🦮 골든리트리버)**: 다정함과 공감의 힐러남
   - **테토녀(🐆 알파걸 흑표범)**: 주관 뚜렷하고 당당한 걸크러시
   - **에겐녀(🐰 러블리 아기토끼)**: 사랑스럽고 섬세한 감성 힐러
   - 테토 vs 에겐 백분율(%) 듀얼 게이지 바 표시
   - **환상의 짝꿍** & **주의할 짝꿍** 궁합 정보 제공
4. **바이럴 공유 최적화 기능**:
   - **결과 카드 이미지 저장 (html2canvas)**: 인스타그램 스토리(9:16)에 바로 올릴 수 있는 PNG 캡처 다운로드
   - **카카오톡 공유 API**: 카카오톡 피드 템플릿 연동 구조 내장
   - **원클릭 링크 복사**: 클립보드 복사 및 부드러운 토스트 팝업 알림
   - **결과 축하 효과**: canvas-confetti 폭죽 애니메이션

## 🚀 바로 실행하는 방법

별도의 서버 설치나 복잡한 빌드 과정(npm/Node.js) 없이 **웹 브라우저에서 바로 실행**할 수 있습니다.

1. 파일 탐색기에서 `c:\안티크래비티\테토 에겐\index.html` 파일을 찾습니다.
2. `index.html` 파일을 더블 클릭하거나 크롬(Chrome), 엣지(Edge) 등의 브라우저로 드래그합니다.
3. 테스트를 직접 진행해보고 결과 화면 및 공유 기능을 확인합니다.

## 🌐 무료 웹 배포 방법 (초간단 3가지)

누구나 접속할 수 있도록 웹 링크로 배포하고 싶을 때 아래 방법 중 하나를 선택하세요:

### 1) Vercel 배포 (가장 추천 - 1분 소요)
1. [Vercel](https://vercel.com)에 로그인합니다.
2. Vercel 대시보드에서 `Add New...` -> `Project` 선택 후 이 폴더를 올린 GitHub 저장소를 연결하거나,
3. Vercel CLI 또는 드래그 앤 드롭으로 업로드하면 바로 영구적인 무료 HTTPS 주소(`.vercel.app`)가 생성됩니다.

### 2) Netlify 배포
1. [Netlify](https://app.netlify.com/drop)의 Drop 페이지에 접속합니다.
2. 이 `테토 에겐` 폴더를 통째로 웹 화면에 드래그 앤 드롭하면 5초 만에 배포 완료!

### 3) GitHub Pages 배포
1. GitHub에 새 Repository를 생성하고 파일들을 Push합니다.
2. Repository `Settings` -> `Pages` -> Source를 `main` 브랜치의 `/ (root)`로 설정하고 저장합니다.
3. 약 1분 뒤 `https://<아이디>.github.io/<저장소명>/` 주소로 접속 가능합니다.

## 🔑 카카오톡 공유 기능 활성화 방법 (선택 사항)

카카오톡 공유 버튼을 정식으로 활성화하려면:
1. [카카오 개발자 센터](https://developers.kakao.com)에서 무료 회원가입 후 '내 애플리케이션'을 생성합니다.
2. **JavaScript 키**를 복사합니다.
3. `js/app.js` 파일 최하단 또는 `index.html`에서 `Kakao.init('YOUR_JAVASCRIPT_KEY');`를 호출하도록 키를 넣어주시면 됩니다.
*(키가 설정되지 않은 상태에서는 자동으로 링크 복사 기능으로 대체 실행됩니다.)*
